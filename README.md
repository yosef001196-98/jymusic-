# JY Music 🎵

A sleek, modern, dark-mode Android music player built with **Jetpack Compose** and **Kotlin**.

## ✨ Features
- 🎧 **Device Audio Scanning**: Plays local MP3, M4A, and audio files directly from device storage.
- 🎛️ **Equalizer & Sound Effects**: Adjust Bass, Mid, and Treble (-15dB to +15dB).
- ⏱️ **Sleep Timer**: Auto-pause music after 15, 30, 45, or 60 minutes.
- ⏩ **Playback Speed Control**: 0.5x to 2.0x playback rates.
- 📝 **Lyrics**: View and edit lyrics for any track.
- 📑 **Playlists & Multi-Select**: Auto-playlists (Liked Songs, Recently Played, Most Played) and custom user playlists with batch song additions.
- 📱 **Sleek Spotify-style UI**: Pitch black AMOLED styling with vibrant neon green glow and interactive Now Playing screen.

## 📦 Download APK
To download the compiled APK:
1. Go to the **[Actions](../../actions)** tab in this repository.
2. Click on the latest workflow run ("Build Android APK").
3. Scroll down to **Artifacts** and download **`JY-Music-Debug-APK`**.
4. Install on your Android device!
